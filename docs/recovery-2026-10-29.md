# 2026-10-29 서비스 복구 기록

사용자 승인에 따라 원본 프로젝트를 보존하고 별도 Firestore에 초기 데이터를 적재해 서비스를 재개했습니다. 기존 대화와 사용자가 수정한 기록을 복구한 것은 아닙니다.

- 원본 프로젝트: `power-assistant-edca4` — 프로젝트 삭제 취소 완료. 전환 당시 Firestore는 `Cannot serve requests because the database was deleted.` 오류를 반환했습니다.
- 현재 서비스 프로젝트: `seatscope-recovery-261029`
- 데이터베이스: `(default)`, 서울 `asia-northeast3`, 삭제 방지 활성화
- 초기 데이터: 예약 120건, 총 예약 4,378건, 데모 대화 1건
- 백엔드: https://seatscope-ai-api.onrender.com
- 프런트엔드: https://seatscope-ai.vercel.app

`FIREBASE_PROJECT_ID`로 대상 프로젝트를 지정합니다. 미지정 시 서비스 계정의 기본 프로젝트를 사용합니다. Render의 `firebase.json` 시크릿 파일은 복구 프로젝트의 전용 서비스 계정이며, 해당 계정에는 `roles/datastore.user`만 부여했습니다. 로컬 인증키 파일과 `.env`는 Git에서 제외됩니다.

Render에 `ACTION_API_KEY`를 설정했고 같은 값을 로컬 `.env`에도 저장했습니다. GPT Actions 클라이언트는 해당 값을 Bearer 인증으로 사용해야 합니다. 키는 문서나 Git에 기록하지 않습니다.
